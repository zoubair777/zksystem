# Z.G ERP — نظام إدارة محل ملابس (جملة وقطاعي)

نظام ويب لإدارة المبيعات والمخزون والحسابات لمحل ملابس في ليبيا (الدينار الليبي)، مبني على
Flask + SQLite بواجهة عربية (Bootstrap RTL). يعمل على كمبيوتر المحل، ويفتح من أي جهاز على نفس
الشبكة (كمبيوتر ثاني، تابلت، تليفون) عن طريق المتصفح.

أهم ما فيه: نقطة بيع بالباركود، ورديات وخزائن، مرتجعات واستبدال، مشتريات بعملة المورد
(دولار، جنيه مصري، ليرة...) مع سعر الصرف، حسابات بنكية وخزائن عملات، مصاريف شراء تدخل في التكلفة،
مرتجع مشتريات، المركز المالي، تقارير PDF/Excel، طباعة ملصقات باركود مباشرة على طابعة الملصقات،
ونسخ احتياطي تلقائي محلي وعلى Google Drive.

سجل التعديلات وأسبابها: [`ZG_CHANGES.md`](ZG_CHANGES.md). قواعد العمل على الكود: [`CLAUDE.md`](CLAUDE.md).

## محتويات المستودع
| الملف | الوظيفة |
|---|---|
| `app.py` | كل الصفحات والمنطق |
| `models.py` | جداول قاعدة البيانات |
| `config.py` | الإعدادات ومكان قاعدة البيانات |
| `backup_service.py` | النسخ الاحتياطي (محلي + Google Drive) |
| `export_service.py` | تصدير Excel وPDF |
| `label_service.py` | باركود Code128 وطباعة الملصقات (TSPL) |
| `desktop_launcher.py` | تشغيله كنافذة برنامج على ويندوز |
| `templates/`, `static/` | الواجهة (الصفحات، الخطوط، Bootstrap) |
| `docs/accounting_audit_test.py` | 35 فحصًا حسابيًا (يشتغل على نسخة مؤقتة) |
| `reset_admin_password.py` | استرجاع كلمة مرور المدير عند نسيانها |
| `start.bat` / `start_desktop.bat` / `build_exe.bat` | التشغيل وبناء `ERP.exe` |

**غير موجود في المستودع (عن قصد):** قاعدة البيانات `database/`، النسخ الاحتياطية، والبرنامج الجاهز
`dist/`. فيها بيانات المحل الحقيقية ومفاتيح Google وAI، ولا تُرفع على GitHub (انظر `.gitignore`).

## التشغيل على ويندوز
```bat
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
ثم افتح `http://127.0.0.1:5000`. أو اضغط مرتين على `start.bat`.

قاعدة جديدة فارغة تُنشأ تلقائيًا بحساب `admin` / `admin123`. غيّر كلمة المرور فورًا،
وضع مفتاحًا عشوائيًا في `ERP_SECRET_KEY` (انظر `.env.example`).

لنقل بيانات محل موجود: انسخ مجلد `database` (فيه `erp.db` وأحيانًا `erp.db-wal` و`erp.db-shm`)
والبرنامج مقفول، بجانب `app.py` أو بجانب `ERP.exe`.

## الفتح من التليفون أو جهاز ثاني
النظام صفحات ويب متجاوبة، فيفتح على التليفون من المتصفح بدون تطبيق:
1. شغّل النظام على الكمبيوتر بـ `start.bat` (يسمع على الشبكة المحلية، المنفذ 5000).
2. التليفون على نفس شبكة الواي فاي. اعرف رقم الكمبيوتر بأمر `ipconfig` (IPv4)، مثلاً `192.168.10.7`.
3. افتح على التليفون: `http://192.168.10.7:5000` وسجّل الدخول بحساب الموظف.
4. إذا ما فتحش: اسمح لبايثون في جدار حماية ويندوز على الشبكة الخاصة.

ملاحظة: `ERP.exe` (نافذة البرنامج) يفتح على الكمبيوتر نفسه فقط (`127.0.0.1`).
للتليفون استعمل `start.bat`. قاعدة البيانات تبقى على الكمبيوتر الرئيسي فقط.

للفتح من برّا المحل (من البيت مثلاً) يلزم لاحقًا رفعه على سيرفر أو استعمال نفق آمن،
مع HTTPS وحماية CSRF قبل ذلك.

## بناء البرنامج الجاهز ERP.exe
شغّل `build_exe.bat` على ويندوز فيه بايثون. يبني في مجلد مؤقت ثم يبدّل `dist\ERP\ERP.exe`
و`_internal` فقط، ولا يلمس `dist\ERP\database`.
