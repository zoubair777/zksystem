# خط عربي لتصدير PDF

ضع هنا ملف خط TTF يدعم العربية باسم `arabic.ttf` (مثل خط Cairo أو Amiri أو
Noto Naskh Arabic) حتى تظهر النصوص العربية بشكل صحيح ومتصل الحروف داخل
ملفات PDF المُصدَّرة من `/reports/export/pdf`.

خطوات سريعة:
1. حمّل خطًا مجانيًا (مثال: Google Fonts → Cairo أو Amiri).
2. انسخ ملف `.ttf` إلى هذا المجلد وأعد تسميته `arabic.ttf`.
3. ثبّت الحزم الإضافية: `pip install arabic-reshaper python-bidi` (موجودة في requirements.txt).
4. أعد تشغيل الخادم.

إن لم يوجد الخط أو الحزم، سيستمر التصدير في العمل بدون توقف لكن قد يظهر
النص العربي غير متصل الحروف أو معكوس الاتجاه.
